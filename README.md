# 🦷 Domain-Specific Adaptation of GPT-2 for an AI-Powered Dental Chatbot - AI-Dental-Chatbot-NLP

This project fine-tunes GPT-2 for the dental domain to build an intelligent chatbot capable of answering oral health queries.

## 📂 Files
- `Domain-Specific_Adaptation_GPT2_Dental_Chatbot.ipynb` — Main notebook
- `Report.docx` — Project report
- `requirements.txt` — Python dependencies

## 🧠 Model
Uses Hugging Face Transformers for fine-tuning GPT-2 with domain-specific dental text corpus.
