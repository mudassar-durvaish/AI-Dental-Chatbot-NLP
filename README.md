# 🦷 Domain-Specific Adaptation of GPT-2 for an AI-Powered Dental Chatbot - AI-Dental-Chatbot-NLP

This project fine-tunes GPT-2 for the dental domain to build an intelligent chatbot capable of answering oral health queries.

## 📁 Project Files

| File Name | Description |
|------------|-------------|
| **AI_Tranied_ChatBot_For_Dental_Health.ipynb** | Main Jupyter Notebook for training and testing the fine-tuned GPT-2 chatbot. |
| **dental_health_dataset (1).csv** | Dataset containing domain-specific text data for model training. |
| **Final_Report.docx** | Complete project report with methodology, results, and evaluation. |
| **Research_Paper.docx** | Research documentation summarizing findings and future work. |
| **README.md** | Overview and documentation for the repository. |

---

## 🧠 Model
Uses Hugging Face Transformers for fine-tuning GPT-2 with domain-specific dental text corpus.
